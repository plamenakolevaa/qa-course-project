# QA Course Project – Manual Testing

## Description
This project contains **manual testing artifacts** created during a QA course.  
All testing was performed on the practice website: [Agileway Travel](https://travel.agileway.net/login).

## Test Cases
Test cases were written in Zephyr and exported to Excel.  
- See `test_cases.xlsx`  
- Includes functional, UI, and regression tests

## Bug Reports
Bugs discovered during testing are documented in Jira.  
- See `bug_reports.xlsx`  
- Columns include Bug ID, Summary, Description, Severity, Status  

## Screenshots
Screenshots provide visual evidence of defects and test execution

## Tools Used
- Jira  
- Zephyr  
- Excel  

## Notes
- All data is for **educational purposes**  
- No sensitive information is included
